# Curso de Análisis de Algoritmos

Repositorio correspondiente al curso de Análisis de Algoritmos de Ingeniería de Sistemas.

## Estructura del repositorio

El repositorio está organizado de la siguiente manera:

- `laboratorios/`: contiene los cinco informes de laboratorio evaluativos del semestre.
- `ejercicios-clase/`: contiene los ejercicios desarrollados durante las sesiones prácticas.
- `benchmarks/`: contiene scripts utilizados para medir tiempos de ejecución y generar gráficas.

## Flujo de trabajo

El trabajo del curso seguirá un flujo básico:

1. Desarrollar los ejercicios localmente.
2. Verificar los cambios con `git status`.
3. Revisar las diferencias con `git diff`.
4. Agregar los cambios al staging.
5. Crear un commit descriptivo.
6. Sincronizar con GitHub mediante `git push`.
